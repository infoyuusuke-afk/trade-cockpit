# C-076 人気テーマ・グロース株のOR15継続監視（検証仕様）

## 目的と現状

パワーエックス（485A）とTerra Drone（278A）のような、人気テーマの高ボラティリティ銘柄を寄り後から継続監視する。両銘柄は既存の100銘柄監視リストにあるが、監視対象への登録だけでは売買サインは発動しない。2026-09-18のPC側記録では09:00〜09:15の100銘柄データが欠けており、同日の寄り後シグナルや前日OR15支持の主張をその記録だけで検証できない。現状の実績を「発動済み」「優位性確認済み」と表示しない。

## 入力と鮮度ゲート

各銘柄について、前営業日の取引日付き09:00〜09:15の完成足3本と、当日09:00〜09:15の完成足3本を必須とする。価格、出来高、VWAPは同一取引日・同一ソース系列の完成足から時点順に計算する。異なる系列を照合する場合はコード、取引日、価格、更新時刻を別々に確認する。欠測、日付違い、遅延、特別気配中、出来高比較の基準不足は `WAIT_DATA` とし、売買候補を出さない。前日OR15安値を当日のOR15安値と混同しない。

人気テーマの判定は、時点付き材料・関連性と、同時間帯の売買代金・相対出来高・市場全体/同テーマの広がりを別々に記録する。テーマ名だけで方向を決めない。銘柄選択の母集団は寄り前に固定し、引け後に上がった銘柄だけを遡って追加しない。

## 2段階の候補ルール（閾値は仮置き）

| 段階 | 条件 | 表示 |
|---|---|---|
| 早期監視 | 09:15以降、当日OR15高値を完成足終値で上抜き、同時点VWAPより上。出来高とテーマ・市場反応を確認する | `WATCH`。押し目が無くても上昇を見逃さないための注意表示で、買い発動ではない |
| 押し目確認 | 上抜き後、完成足が当日OR15高値またはVWAP付近まで戻って下ヒゲ・高値更新等で反発し、支持線上で確定。反発足の出来高が比較可能な同時間帯の基準を上回る | `CANDIDATE_LONG`。エントリー候補時刻、支持線、無効化価格を同時に記録する |
| 前日OR15支持 | 当日、**前日**OR15安値近傍への接近を時点付き足で確認し、その後に安値切り上げ・当日VWAP回復・出来高増加を確認する | 別型の `CANDIDATE_LONG`。前日安値から離れたまま上昇しただけなら「支持確認」と呼ばない |

高値上抜きだけで即買いにせず、早期監視と売買候補を分ける。VWAP/OR15からの乖離、板の薄さ、スプレッド、急な逆行が大きいときは候補を取り消す。撤退候補は押し目安値または支持線割れ、時間切れ、1Rの損失上限で比較する。利確・保有時間の最適値は過去2銘柄の目視から決めず、手数料と滑り込みの検証で決める。平均取得単価を下げる追加買いはルールに含めない。

## 受入条件

1. 次の取引日に寄り前から100銘柄収集が動き、09:00〜09:15の有効な完成足を保存する。データが欠ける日は `WAIT_DATA` が出ることを確認する。
2. 485A・278Aを含む寄り前固定の監視銘柄について、各段階の発見時刻、根拠足、同時点VWAP、当日/前日OR15、出来高、テーマ根拠、見送り理由を記録する。
3. 見逃し・誤報・支持線割れ・逆行幅を実際の発生順で追跡する。少なくとも複数日・複数銘柄の前向き記録で、追随のみ・押し目確認・前日支持型を別々に比較する。
4. 手数料、スプレッド、滑り、売買停止や特別気配、寄り前に選んだ母集団を反映し、純期待値と損失側の分布を確認するまでは正式な売買サインに昇格しない。

本仕様は検証候補であり、実発注・執行系・既存売買サインを変更しない。
