V10 local data health adapter v1: current Gateway /health collector_status and watcher_status strings do not contain independent per-source timestamps. The adapter therefore accepts only independently timestamped source-health records, and leaves missing sources BLOCKED. No interpolation, no timestamp substitution from local file mtime or current time. The separate V10 Gateway fail_closed/price_source_status/data_conflict check must pass even if source records look healthy. All healthy is OBSERVATION_CANDIDATE_ONLY, not market data source authentication and not permission to trade. This is a pure offline adapter; wiring into the running Windows processes is still pending. Do not upload private data or change Excel/Watcher/Brain in this phase.
