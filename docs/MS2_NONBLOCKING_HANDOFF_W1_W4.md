# MS2非ブロッキング記録経路のWindows受入（未実施）

この手順は市場が閉まっている時間に、OWNERのWindows実機で行う。このリポジトリ上の実装とテストはLinux上のオフライン検証であり、ここには合格を書かない。四項目とも状態は `NOT_VERIFIED`。

合格するまで、Watcherへの接続、自動起動、フラグの常時オン、mainへのマージはしない。

対象は取得済みの `$board` を固定長で渡す独立Writerである。Watcher本体 `ms2_live/Kioxia_RSS_Live_Watcher.ps1` はこの変更に含まれない。手順の途中でそのファイルを編集しない。

## 共通の禁止

- Excelを `Stop-Process` または `taskkill` で終わらせない。強制終了は既知のCOM `0x80004002` を招く。
- RssOrder、実注文、証券会社へのログインをしない。
- `data/private/ms2_sidecar` の中身をGitHub、Issue、Actionsのログへ出さない。価格と板数量の生値は控えない。
- 既存の `kioxia_ticks_*.csv`、`kioxia_tick_diag.csv`、気配値ログを削除しない。
- タイムゾーンが無い時刻に `+09:00` を足さない。`poll_seq` を取引所の約定順として扱わない。

## 中止

次のどれかが出たらフラグをオフに戻し、WatcherのコンソールだけをCtrl+Cし、現行のWatcherスクリプトのままにする。

- COMのエラーダイアログ、Excelの無応答、売買サインの凍結。
- 5秒を超えるポーリングの空き。
- コンソールが落ちる。
- Writerを止めたのに現在値、音声、サインが止まる。

## 復旧

1. WatcherコンソールをCtrl+Cする。`RSS接続!B16` が「停止」になり、Excelは開いたままであること。
2. Writerプロセスが残っていたら、そのPythonプロセスだけを終了する。Excelは触らない。
3. sidecarフラグをオフに戻す。
4. private JSONLが壊れていても追記しない。必要なら `data/private/ms2_sidecar/quarantine` へコピーし、tickログと気配値ログは残す。
5. この状態のまま本番の記録を有効にしない。

## W1 起動と現行経路

1. 市場外であることを確認する。自動起動は使わず、手動で現行Watcherだけを起動する。sidecarフラグはオフ。
2. 現在値、音声、売買サイン、板の表示が、フラグを付ける前と同じ順序で更新されること。
3. `data/private/ms2_sidecar` に新しいJSONLが増えないこと。
4. `Read-BoardDepth` は従来どおり1回、セル読取は40回のままであること。追加の `Value2` が無いこと。

合格は、フラグオフのあいだ既存経路が続き、private領域が空のままであること。未実施。

## W2 COM競合とポーリング遅れ

1. 別途OWNERがWatcher接続を承認したあとに限る。市場外だけ。
2. 先にフラグオフで60秒の基準を取る。数えるのはポーリング間隔、COMエラー件数、CPU、破棄件数だけとする。
3. フラグをオンにし、同じ60秒を取る。現在値、音声、サインが基準と同じように動くこと。
4. COMエラー件数が基準より増えないこと。サインが凍結しないこと。

合格は、追加COMが0で、既存の2秒ループがWriterのディスク待ちで止まらないこと。未実施。

## W3 Writer障害

市場外のまま、次を一度ずつ行う。Watcherは止めない。

1. 書込先を権限のないパスにする。
2. 書込先の容量を尽くす。
3. 出力ファイルを別プロセスがロックする。
4. Writerプロセスだけを強制終了する。

各回で現在値、音声、サインが続くこと。破棄件数、fail-closed件数、ワーカー死亡件数が数として残り、価格そのものは残さないこと。再試行で2秒待機を引き延ばさないこと。privateファイルは公開しない。

合格は、障害中も監視ループが生きていること。未実施。

## W4 停止とExcel残留

1. WatcherコンソールだけをCtrl+Cする。
2. Writerの終了待ちは0.25秒を上限とし、残ったらWriterのPythonプロセスだけを切る。
3. Excelは開いたままである。Excelのプロセスを新しく残さない。Watcherが元から使っていたExcelを強制終了しない。
4. `RSS接続!B16` が「停止」になること。tickログと気配値ログが残っていること。
5. フラグをオフに戻す。

合格は、停止後にExcelが残り、Watcher由来の強制終了が無いこと。未実施。
