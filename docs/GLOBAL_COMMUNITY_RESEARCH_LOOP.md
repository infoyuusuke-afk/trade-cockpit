# Global Community Research Loop v1

Overseas trader replies can be valuable, but popularity is not evidence.

Flow: Global Japan-market brief → community reply/lead → quarantine as UNVERIFIED_RESEARCH_LEAD → independent verification → optional VERIFIED_RESEARCH_INPUT → Strategy Lab / editorial research.

Unverified community claims cannot change a trading signal, P/L evidence, or a factual publication statement. Private data is rejected. No order path is exposed.

This creates a two-way research loop without treating social-media confidence as market truth.
