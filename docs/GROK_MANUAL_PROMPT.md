# Grokの情報を手動でAIコクピットへ渡す（OWNER 2026-10-23）

自動連携（API）は保留。お金はかからない形で、Grok（Cursor）の答えを手で渡します。
Grokは監視だけです。売買の判断はブレインがします。点数・ゲート・注文には使いません。

## 手順

1. 下の「Grokへの質問」をGrokに貼って送る。
2. Grokの答えを全部コピーする。
3. デスクトップの「Grok情報をコクピットへ」を押す。
   - OK：受け取った銘柄と有効な時刻が出ます。
   - NG：理由が出ます（その答えは保存しません）。
4. 画面のREALTIMEタブ、期待値ランキングの「Grokの情報」に出ます。
   ブレインの選択に同じ銘柄があると、その欄にGrokの情報が付きます。
   サインと逆向きの情報には「注意」と付きます。

有効なのは as_of から8時間（その日のうち）です。

## Grokへの質問（このまま貼る）

```text
日本株のデイトレード用に、X（旧Twitter）と海外ニュースを調べてください。
対象：東証の半導体・ハイテク関連と、今Xで急に話題が増えている東証の銘柄。
期間：前日の大引け（15:30）から今まで。

答えは次の形だけで書いてください。説明や前置きは書かないでください。

GROK_NOTE_V1
as_of: YYYY-MM-DD HH:MM（日本時間の今の時刻）
銘柄コード4文字 | 種類 | 要約（120文字まで、日本語） | 出典URL（httpsで始まるもの。1〜3個、空白で区切る）
END

決まり：
- 種類は 好材料・悪材料・話題・噂 のどれか1つ。確認できないものは「噂」。
- 1銘柄1行、最大15行。同じ銘柄は1行にまとめる。
- 出典URLのない行は書かない。
- 推測で値段や数字を作らない。
```

## 例

```text
GROK_NOTE_V1
as_of: 2026-10-23 07:40
285A | 話題 | 米国のメモリー価格の報道でXの投稿が急増 | https://example.com/news/1
6857 | 悪材料 | 海外の大口顧客が発注を延期との報道 | https://example.com/news/2
END
```
