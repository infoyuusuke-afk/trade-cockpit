# GPTアナリストの意見を手動で取り込む（予備・OWNER 2026-10-23）

8:30・12:15の自動実行が失敗した時、またはレポートが届かなかった時だけ使う予備です。
ChatGPTの画面（アプリかブラウザ）で各アナリストに聞き、その答えを手で渡します。新しいAPIの費用はかかりません。

- その時間帯（12:15より前は8:30の回、12:15以降は12:15の回）の自動レポートが届いている時は使いません
  （「自動のレポートが届いているので使いません」と出ます）。
- 画面のAIアナリスト欄に『手動』と付けて出します。売買の点数は変えません。判断はブレインです。
- Revenue Hunterは売買とは別の仕事なので、ブレインの監視には入れず、アナリスト欄に出すだけです。

## 手順

1. 下の担当ごとの質問を、ChatGPTに貼って送る（必要な担当だけでよい）。
2. 答えを全部コピーする。
3. AIコクピットフォルダの「4_アナリスト意見をコクピットへ.cmd」を押す
   （または決まったフォルダ「アナリストの答え」にテキストファイル（.txt）で保存する）。
4. OK：受け取った件数が出ます。NG：理由が出ます。

答えの形（4人とも同じ）：

```text
GPT_ANALYST_NOTE_V1
アナリスト名 | 銘柄コード4文字 | 強気/弱気/監視 | 理由（120文字まで） | 出典URL（https） | 時刻（YYYY-MM-DD HH:MM 日本時間）
END
```

アナリスト名は 寄り前・PRE-NEXT・需給・Revenue Hunter のどれか。Revenue Hunterは銘柄コードの代わりに「-」でもよい。
