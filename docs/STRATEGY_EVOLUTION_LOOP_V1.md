# Strategy Evolution Loop v1

AI Cockpit should not inherit a human trader's rules as truth. OR15, VWAP, short-timeframe entry rules, opening-break ideas and externally sourced trader methods are strategy candidates until evidence earns promotion.

Lifecycle: CANDIDATE → REPLAY → SHADOW → PROMOTION_CANDIDATE. Evidence-integrity failure or non-positive measured expectancy demotes a strategy. Out-of-sample evidence is required before Shadow; measured Shadow evidence is required before becoming a live-promotion candidate.

The initial sample threshold is contract scaffolding, not proof of profitability. Strategy Lab must later calibrate thresholds by setup, regime, symbol class, execution model and statistical uncertainty.

No state in this module grants real broker submission.
