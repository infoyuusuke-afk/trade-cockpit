# Autonomous Daily Loop v1

This planner expresses the target routine without requiring the Owner to press “進めて”.

Cycle: acquire approved evidence → validate freshness/integrity → analyze in Strategy Lab → produce a shadow/eligible decision → evaluate expectation versus result → prepare JP/Global internal reporting → learn from strategy and incident outcomes.

If evidence is unavailable, the loop attempts the approved recovery path and ends in WAIT_DATA rather than inventing inputs. Closed markets produce no market-order decision.

This v1 plans work only. It does not schedule itself, control Windows, submit broker orders or publish externally.
